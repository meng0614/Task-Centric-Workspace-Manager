# Workspace Standard

The workspace root contains broad domains, but real work lives in tasks.

```text
E:\codex
|-- skills
|-- media
|-- research
|-- projects
|-- downloads
|-- logs
|-- temp
`-- archive
```

A task folder is the atomic unit of organization:

```text
YYYYMMDD_TaskName/
|-- input
|-- output
|-- logs
|-- assets
|-- temp
`-- archive
```

Global file-type folders should be treated as staging or legacy only.
